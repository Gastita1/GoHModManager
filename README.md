# 地狱之门 · 模组管理器  (GoH Mod Manager Plus)  v1.1

给《Call to Arms - Gates of Hell》用的第三方模组管理器。
参考了 alexbdka 的旧版 GoH Mod Manager（那个从创意工坊被下架的版本）重写，
并且能直接读取它的配置和预设。

## 一、怎么用

1. 双击 GoHModManager.exe。
2. 左边是「目录」——你创意工坊里订阅的、以及游戏 mods 文件夹里的所有模组。
   点一下看详情，点名字左边的方框（或双击）加入右侧加载顺序。
3. 右边是「加载顺序」——从上到下依次加载，越靠下的模组会覆盖越靠上的。
   可以拖拽排序，也可以用 上移/下移，或 Ctrl+↑ / Ctrl+↓。
   有的模组说明里写「place this mod last」，就把它拖到最下面。
4. 点右下角「保存并应用」，写入游戏的 options.set。下次启动游戏生效。
5. 点「启动游戏」直接通过 Steam 开游戏。

## 二、功能

· 自动找路径：从 Steam 注册表 + libraryfolders.vdf 找游戏、创意工坊、存档配置
· 双栏管理：目录 + 加载顺序，拖拽排序
· 依赖检查：读 mod.info 的 require，缺依赖会提示并可以一键补上
· 文件冲突：检测多个模组改同一个文件的路径，列表里标 ⚠，菜单里能看明细
  支持松散文件、.pat 与 .pak（MACE 等把改动打包进 .pak 的大模组也能检测）
· 版本兼容：按 min/maxGameVersion 对比当前游戏版本，不兼容会标出来
· 损坏检测：空目录、缺 mod.info（比如那个已下架的 3539729649）会标「无法加载」
· 预设：一套顺序存成预设，一键切换（比如「剧情一套」「联机一套」）
· 自动备份：每次写入前把 options.set 备份到 config\backups\，可一键还原
· 分享码：把当前加载顺序（或某个预设）压成一段 eJz… 的码发给朋友，
          他在「导入分享码」里粘贴就能得到完全一样的顺序 —— 联机对局必备
· 本地模组：支持把 .zip 或文件夹拖进窗口导入到游戏 mods 目录
· 封面/详情：点一下就显示模组自带 logo.jpg、ID、大小、文件数、标签、简介
· 多语言：右上角按钮切换 简体中文 / English / 日本語 / 한국어 / Español / Français / Deutsch / Русский，
        首次启动按系统语言自动选择，选择结果保存在 config.json
· 作者：联网从 Steam 公开接口取作者名 / 订阅数 / 更新时间并缓存；
        取不到时自动从简介里推断（"By X"、"Developed by X"、"作者：X"），
        并在后面标「（据简介）」；右键菜单里可以手动重新联网获取

## 三、快捷键

Ctrl+S    保存并应用
Ctrl+E    导出分享码
Ctrl+I    导入分享码
Ctrl+L    切换语言（循环）
F5        重新扫描
Del       从加载顺序里移除选中项
Ctrl+↑/↓  加载顺序里上移 / 下移

## 四、数据放哪

config\config.json   —— 本程序的设置和预设
config\log.txt       —— 运行日志（出问题看这个）
config\backups\      —— options.set 的历史备份（保留最近 40 份）
config\cache\        —— 作者 / 订阅数 / 更新时间的缓存（联网拿到后自动存）

如果你把旧的 GoH Mod Manager 配置留在 %USERPROFILE%\.goh-mod-manager\config.json，
本程序第一次启动时会自动导入它的路径和预设。

注意：游戏正在运行时写 options.set，退出游戏时可能被内存里的设置覆盖。
程序会检测并在写入前提醒你，最好先关掉游戏再保存。

## 五、关于「创意工坊」

Steam 创意工坊只能发布「游戏内容」（模组），发布不了可执行程序。
旧的管理器是以模组形式挂在创意工坊里的，所以会被 Valve 按「非模组内容」下架 —— 
这也是它消失的原因。所以这个版本做成本地独立 exe，不需要联网、不需要创意工坊条目，
但它管理的就是你创意工坊里订阅的模组。

## 六、分享码怎么工作

格式和旧版一样：JSON -> zlib 压缩 -> Base64，所以码都是以 eJz 开头的。

  {"v":1,"app":400750,"name":"预设名",
   "mods":["mod_2707749899", ...],
   "titles":{"mod_2707749899":"Mount everything", ...}}

其中 titles 是可选的模组名（旧版码里没有这个字段也能正常导入）。

· 导出：菜单「⋯ → 导出分享码…」或 Ctrl+E，可以选「当前加载顺序」或某个预设，
  点「复制到剪贴板」直接发出去。
· 导入：菜单「⋯ → 导入分享码…」或 Ctrl+I，粘贴后点「导入」。
  程序会自动套用顺序；你还没订阅的模组会弹一个「缺少 N 个模组」窗口：
    - 列表里显示模组名（导出时会把名字一起打进码里，没名字就显示 ID）
    - 双击 / 「打开创意工坊」→ 直接用 Steam 打开订阅页
    - 「全部打开」→ 一次性打开所有缺的页面
    - 「复制清单（带链接）」→ 得到一段带 https 链接的文字，可以回给房主
  导入后可以直接选择「立即写入游戏配置」。
· 兼容：旧版那种 eJz 码也能读（字段名不是 mods 时会在 JSON 里找模组 ID 数组）。
  反过来，如果对方的旧版只认它自己的格式，就用「预设」手动对齐。

## 七、命令行冲突检测

不打开界面也能扫一遍冲突：

    GoHModManager.exe --scan 输出文件.txt "模组目录1" "模组目录2" ...

输出示例：

    mods: 5 | files: 22011 | conflicts: 33
    entity/-vehicle/generic/special/inf_crate_ger/inf_crate_ger.def
        GoH_Supply_MG
        2978877382

适合放进批处理里，或者给朋友排查“为什么我装了两个模组没效果”。
